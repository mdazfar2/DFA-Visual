# DFA-Visual Contributing Guidelines

Welcome to the **DFA-Visual** project! 🎉  
We're thrilled to have you here. Whether you're an experienced open-source contributor or just beginning your journey, your contributions are **highly valued and appreciated**.  

This project is all about making **Deterministic Finite Automata (DFA)** easy to understand with a **visual simulator and interactive UI**. Your input helps make learning **Theory of Computation** more fun and engaging for everyone! 💡  

---

> **⚠️ IMPORTANT**
>
> - **Pull Requests (PRs) without an associated issue will not be accepted.**  
>   Please get an issue assigned first (either an already opened one or one you raise).  
>
> - **Inactive PRs open for more than 45 days will be automatically closed.**  
>
> - **PRs must pass linting and build checks before merging.**  
>   If the code fails linting or build tests, the PR will not be merged.

---

## 📂 Project Structure

- `frontend/` → Handles the visualization, UI, and interaction logic (React + Tailwind).  
- `examples/` → Contains pre-built DFA examples for quick testing and demos.  
- `docs/` → Documentation files for guides, references, and tutorials.  
- `backend/` → (Optional – future scope) Server-side extensions for saving/loading DFAs, authentication, etc.

---
